## 👋 Sobre mim

Sou de São Paulo e trabalho desde fevereiro de 2025 no time de **Infraestrutura & Help Desk da Mtrix (uma empresa NIQ)**.
Entrei como Jovem Aprendiz e fui promovido a estagiário em 10 meses. Hoje dou suporte N1/N2 a mais de 200 usuários.

Em paralelo, curso **Análise e Desenvolvimento de Sistemas na UNIBTA** (formatura prevista para jun/2027) e programo projetos
para gente de verdade, como o sistema de estoque e doações da Casa Via Matris, cada vez mais com IA no meio do caminho.

- 🛠️ No trabalho: chamados N1/N2 no Jira e no ServiceNow, Active Directory, Windows/Linux, VPN, Microsoft 365 e acessos no Azure
- 💻 Nos projetos: JavaScript, React, Node.js e Python, com testes automatizados e deploy contínuo
- 🤖 Com IA: integração de LLMs via API (Groq/Llama 3) e desenvolvimento assistido pelo Claude
- 🌱 Estudando agora: AWS Cloud Practitioner Essentials e a formação React Developer da DIO
